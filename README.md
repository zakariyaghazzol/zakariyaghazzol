## Engineering projects

- **[Model Rocket Flight Computer](https://github.com/zakariyaghazzol/model-rocket-flight-computer)** — Observation-only C++17 prototype for sensor filtering, flight-state classification, telemetry, and fault detection, with synthetic-flight tests. Hardware integration is in progress; the system has not flown.

- **[LoRa GPS Telemetry and Ground Station](https://github.com/zakariyaghazzol/lora-gps-ground-station)** — Arduino LoRa GPS link and Python ground station. A 5.7-hour bench run logged 20,152 packets with 0.55% reported packet loss; public examples use synthetic positions.

- **[Solar Atlas — Stellarium Catalog Pipeline](https://github.com/zakariyaghazzol/solar-atlas-stellarium-pipeline)** — Node.js binary-data conversion and validation pipeline. Converted 586,525 star records across four catalogs and reduced output size by 33.3%, with synthetic end-to-end tests.
